# Third-party notices

## React Bits

This project uses components and effects from [React Bits](https://reactbits.dev/):

- `Silk` — interactive flowing background
- `GradientText` — animated red headline treatment
- `GlareHover` — pointer-responsive highlight interaction
- `Magnet` — restrained pointer pull on the main action
- `ClickSpark` — click feedback on the main actions
- `SpotlightCard` — pointer-lit setup card
- `ShinyText` — soft highlight sweep on the live label
- `ScrollReveal` and `FadeContent` — section and instruction reveals
- `CountUp` — count of available sync intervals

The components are included as editable source in `components/`; some are lightly adapted to avoid extra dependencies. React Bits is licensed under the MIT License with the Commons Clause. See the [React Bits repository](https://github.com/DavidHDev/react-bits) for the current license text and terms. The components are used as part of this application, not offered as a standalone component library.
